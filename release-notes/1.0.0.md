Film-ing 첫 공개 버전입니다. 필름 사진을 가져와 롤로 정리하고, 고르고, 보정하고, 밀착 인화로 남기는 데까지 한 프로그램에서 할 수 있습니다.
모든 작업은 내 PC 안에서만 하고, **원본 사진은 망가뜨리지 않습니다.**

**설치:** 아래 `Film-ing-Setup-1.0.0.exe` 를 받아 실행하세요(윈도우 10/11 64비트). 처음 실행할 때 “Windows의 PC 보호” 창이 뜨면
**추가 정보 → 실행** 을 누릅니다 — 아직 코드 서명 인증서가 없어서 나오는 안내입니다. 받은 파일의 확인값은 `SHA256SUMS.txt` 에 있습니다.

## 가져오기 · 정리

- **스캔 폴더 추가**(하위 폴더 포함). 켤 때 새 스캔을 찾아 넣고, “최근 가져온 사진”으로 모아 봅니다.
- **현상소 zip 바로 가져오기** — 창에 zip 을 끌어 놓으면 미리보기에서 폴더·롤 이름·필름을 고친 뒤 롤 폴더로 풀어 등록합니다. 받은 zip 은 그대로 둡니다.
- **새 사진 자동 가져오기**(설정에서 켬) — 스캐너가 저장하는 폴더를 지켜보다가, 복사가 끝난 사진만 모아서 넣습니다.
- **바뀐 폴더 찾기** — 폴더 이름을 바꾸었거나 다른 드라이브로 옮겼으면, 지금 있는 폴더를 한 번 골라 다시 연결합니다. 별점·보정·롤 정보가 그대로 따라옵니다.
- **롤별로 묶어 보기** — 롤마다 머리 카드(필름·감도·카메라·날짜·현상소 요약)를 달고 접고 펼칩니다. 사진을 끌어다 롤에 넣을 수 있습니다.
- 필터 막대(별점·필름·카메라·롤·연도 등), 컬렉션, 폴더 이동, 파일 이름 한꺼번에 바꾸기, **한 장 이름 바로 바꾸기**(`F2` — 확장자는 그대로, 같은 이름이 있으면 알려 줌).
- 정렬 방향 바꾸기(촬영일 오래된 순 ↔ 최신 순 등, 정렬마다 따로 기억), **다시 켜면 보던 곳에서**(보던 폴더·롤·필터·사진·스크롤 위치).

## 롤 기록

- 롤 번호, 카메라, 렌즈, **필름(자주 쓰는 89종 내장)**, 감도(EI — 증감 +2 처럼 자동 표기), 현상 방식, 현상소, 스캐너, 촬영 기간.
- 폴더 이름에서 필름·날짜·롤 번호를 알아봅니다(“골드200”, “포트라400” 같은 한글 이름도). 내가 부르는 별칭을 필름에 붙일 수 있습니다.
- **현상 기록**(현상액·희석·시간·온도·교반), **네거티브 보관 위치**(바인더·쪽·줄), **현상소 맡김과 비용**(맡긴 날·받은 날·필름값·현상비·스캔비).
- 롤 기록 **엑셀·CSV 내보내기·가져오기**, 현상소·비용 모아 보기(연도·월·현상소별 합계, 컷당 비용).
- 휴대폰 촬영 기록 앱의 기록을 가져와 프레임마다 조리개·셔터·시각·장소를 채웁니다. **위치(GPS)는 사진 파일에도 적습니다** —
  카메라나 다른 프로그램이 이미 적어 둔 위치는 덮어쓰지 않고, 사진 정보 패널에서 고도·지우기·지도에서 보기를 쓸 수 있습니다.

## 고르기

- 별점, **고름/제외**(P/X — 제외를 한 번 더 누르면 밀착 인화에서 낙서로 가림), 색 표시, 평가하고 바로 다음 사진으로.
- **비교 보기**(최대 6장), **확대**(`Z`·사진 클릭: 맞춤 → 100% → 200%, 휠로 자유롭게), **전체 화면**(`F`). 고른 사진만 모아 보거나 제외한 사진을 휴지통으로 보냅니다(복원 가능).
- **되돌리기**(`Ctrl+Z`) — 그리드·크게 보기에서도 별점·고름·라벨·정보·롤 넣기·일괄 보정을 차례로 되돌립니다(파일 이동·이름 바꾸기·휴지통은 빼고).

## 보정 (원본은 그대로)

- 보정은 설정값으로만 저장하고 원본 픽셀은 바꾸지 않습니다. `Ctrl+Z` 와 알림의 “되돌리기”로 되돌리고, `Ctrl+Y`(`Ctrl+Shift+Z`)로 다시 합니다.
  되돌리기 기록은 사진마다 따로 남아 다른 사진에 다녀와도 이어집니다. `Ctrl+Alt+V` 로 바로 앞 사진의 톤·색·필름 효과를 가져옵니다.
- **보정 전과 비교** — 사진을 누르고 있는 동안 보정 전(자르기·회전은 그대로), `Y` 로 좌우 나눠 보기(가운데 선을 끌어 옮김).
- **확대해서 보정** — `Z`·`Space` 로 맞춤 ↔ 100%, 휠·트랙패드로 400% 까지. 100% 이상은 내보내기와 같은 계산으로 만든 원본 크기 그림을 보여 줍니다.
- 보정 슬라이더를 누른 뒤 `← →` 로 한 칸씩(`Shift` 10칸), 자르는 중 `X` 로 가로/세로 바꾸기.
- 히스토그램, **네거티브 반전**(직접 스캔한 네거티브용), 화이트밸런스 스포이드·자동, 노출·대비·하이라이트·섀도·블랙/화이트 포인트·채도·흑백.
- **필름 효과 9가지** — 빈티지 컬러, 따뜻한 네거티브, 유통기한 지난 필름, 할레이션, 흑백 인화, 빈티지 흑백, 셀레늄 토닝, 세피아 토닝, 신주쿠 그레인(거친 입자·강한 대비 흑백 — 1.0.1 에서 이름만 바꿨습니다). 세기 3단계.
- **자동 색**(`A` — 그리드에서 여러 장을 골라 한 번에도), **필름 색온도 변환**(`T` — 실내용 필름을 낮에, 낮빛용 필름을 전구 아래서 찍었을 때), **테두리 자동 자르기**(`Shift+R` — 검은 필름 테두리·흰 여백을 찾아 자르고 수평도 맞춤).
- **먼지·흠집 지우기** — 자동으로 찾아 동그라미로 보여 주고 확인한 뒤 적용, 붓·선으로 직접, 여러 장·롤 단위로 한꺼번에. 둘레의 필름 입자 결을 그대로 가져와 메웁니다.
- **클리핑 표시**(`K` — 날아간 곳은 빨강, 뭉개진 곳은 파랑), 자르기(35mm·6×6·6×7·XPan 등)·수평, 프리셋, 같은 롤에 보정 똑같이 적용.

## 출력

- 내보내기 프리셋: 원본 그대로(무손실 복사), 인스타그램 4:5 흰 테두리, 필름 프레임 테두리(35mm/120), 웹, 16비트 TIFF. 롤별 폴더.
- **위치 정보 빼기** — 내보낸 파일에서 GPS 좌표를 지웁니다. 인스타그램·필름 프레임·웹 용도와 인스타그램 피드는 기본으로 켜져 있습니다.
- **지난 설정으로 바로 내보내기**(`Ctrl+Shift+E`), 자주 쓰는 설정을 이름 붙여 두는 **내 내보내기 프리셋**. 흑백 사진은 정보 손실 없이 회색조 파일로, 8비트로 줄일 때는 하늘의 계단 무늬가 생기지 않게.
- **밀착 인화·필름 스트립** — 기본(흰 인화지·타자기 글꼴)과 빈티지(인쇄된 기록 양식), 엣지 프린트, 별점에 따른 빨간 그리스 펜슬 표시, 내 손글씨 서명.
- **네거 슬리브 라벨·롤 색인표** 인쇄(PDF·PNG).
- **인스타그램** — 파노라마를 4:5·1:1 조각으로 나누기, 피드 순서 미리보기, 촬영 정보 캡션.
- **하프프레임 나누기**(`H`) — 한 장에 두 컷이 찍힌 스캔을 컷 두 장으로. 원본 파일은 그대로입니다.
- **긴 작업 멈추기** — 내보내기·밀착 인화·라벨·파노라마 나누기·먼지 찾기(여러 장)·사진 가져오기를 진행 막대 옆 **멈추기**로. 하던 사진까지만 마치고 멈춰 쓰다 만 파일이 남지 않습니다.
  창을 닫을 때 이런 작업이 남아 있으면 **멈추고 닫기 / 끝나면 닫기**를 묻습니다.

## 원본 보호와 보관

- 촬영 정보를 사진 파일에 적을 때는 처음 한 번 묻고, 정보 구간만 바꿔 이미지 데이터는 바이트 그대로 둡니다. 저장 직후 비교해 다르면 취소합니다.
- 처음 상태를 보관해 두어 **“기록 전 원본으로”** 를 누르면 처음 받은 파일과 똑같이 되돌립니다(이름을 바꾸거나 옮긴 뒤에도).
- 정리 기록(롤·별점·보정)은 사진과 따로 `%LOCALAPPDATA%\Film-ing` 에 둡니다. **설정 → 정리 기록 위치…** 에서 다른 드라이브로 옮길 수 있습니다(복사 → 확인 → 모두 같을 때만 바꿈).
- **자동 백업**: 켤 때·하루 한 번·이름 변경과 이동 직전. 만든 즉시 손상 검사, 다른 드라이브에도 사본, 원하는 시점으로 되돌리기.
- **예전 라이브러리 가져오기** — 라이브러리가 비어 있을 때 첫 화면에서, 예전에 쓰던 Film-ing 라이브러리 폴더를 골라 그대로 가져옵니다
  (복사한 뒤 파일마다 확인값을 비교하고, 고른 폴더는 읽기만 합니다).
