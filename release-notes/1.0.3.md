Film-ing 1.0.3 은 **프로그램 창을 Film-ing 자체 창으로 바꾼 버전**입니다. 사진을 다루는 방법이나 보정 결과, 정리 기록은 바뀌지 않습니다.

**받는 방법:** 자동 업데이트를 켜 두셨다면 프로그램이 새 버전을 알려 드립니다. 처음 설치하시는 분은 아래 `Film-ing-Setup-1.0.3.exe` 를 받아 실행하세요.

## 이제 Film-ing 자체 창으로 열려요

- 예전에는 Edge 의 앱 창으로 열었는데, 이제 윈도우에 들어 있는 **WebView2** 로 Film-ing 이 직접 창을 엽니다.
- **작업 표시줄**에 Film-ing 아이콘과 이름으로 따로 보입니다. 작업 표시줄에 고정해 두고 눌러 켤 수도 있어요.
- 제목 줄이 화면처럼 어둡고, 창 크기·위치를 기억해 두었다가 다음에 그대로 엽니다.
- 창 안의 화면, 단축키, 사진·zip 끌어 놓기, 폴더 선택 창은 그대로입니다. 보기 방식 같은 **화면 설정도 그대로 이어집니다.**
- 새로 고침(F5), 개발자 도구(F12), 확대처럼 브라우저에만 있던 기능은 실수로 눌리지 않게 꺼 두었어요. 입력칸의 오른쪽 클릭 메뉴(잘라내기·복사·붙여넣기)는 그대로예요.

## 더 빨리 켜져요

- 아이콘을 누르면 창이 바로 뜨고 **'켜는 중'** 글자부터 보입니다. 준비되면 저절로 첫 화면으로 넘어가요.
- 이미 켜져 있을 때 아이콘을 다시 누르면 새 창을 열지 않고 **켜져 있는 창을 앞으로** 가져옵니다.

## 닫을 때도 안전하게

- 창을 닫으면 아직 보내지 않은 마지막 보정과 화면 상태를 먼저 저장한 뒤 닫습니다.
- 닫자마자 다시 켜도 빈 창이 뜨지 않게, 앞의 창이 다 정리될 때까지 잠깐 기다렸다가 엽니다.
- 업데이트 창의 **지금 다시 켜기** 도 새 창에서 그대로 됩니다.

## WebView2 가 없는 PC 는 예전처럼

- WebView2 는 윈도우 11 에 기본으로 들어 있고, 윈도우 10 도 대부분 설치되어 있습니다.
- 없거나 창을 열지 못하면 **예전처럼 Edge 앱 창으로** 엽니다. 따로 설치하실 것은 없어요.
